# Calendario N2N y correspondencia de repasos, parciales y finales

**Estado global:** Semestre 1 validado en estructura; semestres 2-10 `PENDIENTE_DE_VALIDACIÓN`.  
**Motivo:** para el Semestre 1 se recibieron el horario, los libros y los exámenes oficiales. Las fechas exactas de cada semana siguen en blanco en el horario original («Fecha ______»). Para los semestres 2-10 aún no se entregaron los calendarios ni los materiales.

## Regla de interpretación

Cuando se reciba cada calendario:

1. Se analiza el calendario completo del semestre y se cruza con el texto oficial, el índice de clases y los videos.
2. Se identifica la semana o sesión de **repaso general** de todo lo estudiado hasta ese punto.
3. Se identifica la semana del **examen parcial**, normalmente la siguiente al repaso, pero siempre según el documento.
4. Se identifica la semana o periodo del **examen final**.
5. Si una fecha o semana no puede determinarse con certeza, se registra `PENDIENTE_DE_VALIDACIÓN`.
6. Si el calendario coloca el parcial en otra semana, se respeta y se documenta la diferencia.

## Estructura de carpetas ya preparada

Cada semestre cuenta con `05_REPASOS_SEMANALES` y `06_PARCIALES_Y_FINALES`, incluida la separación entre versión de estudiante, clave privada y auditoría. Ver `docs/drive-structure-courses-workshops.md` para los IDs y URLs reales.

## Cómo completar esta tabla

1. Sube el calendario a `01_SEMESTRE_XX/00_PROGRAMA_Y_CALENDARIO/`.
2. Registra en esta tabla la semana/fecha, la etiqueta textual original, las clases y páginas abarcadas, el tipo de evento, el archivo y la página exacta.
3. Crea el repaso en la plataforma con la semana indicada.
4. Crea el parcial y el final con su ventana y fuente.
5. Cambia el estado a `VALIDADO` solo cuando la fuente esté citada y el documento/evaluación exista.

## Advertencia

No se debe generar un repaso, parcial o final «operativo» hasta que exista trazabilidad a una fuente oficial. La preparación técnica ya está implementada y probada; la carga curricular real es la que falta.
